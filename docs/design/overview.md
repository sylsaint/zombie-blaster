# 设计总览

> v0.1，2026-10-09，游戏策划。竖屏手机，Godot 4，低多边形 3D（美术方向 B）。数字都是首版可调值，调数值只改 `data/` 里的资源，不改代码。

## 一句话

小队沿桥面自动推进，玩家左右拖动选门加人、升武器，沿途割草清怪、吃升级三选一，关底和 Boss 正面硬刚；通关拿奖励升级局外，打更难的关。

## 三个方案

| | A：纯门跑酷射击 | B：门跑酷 + 局内三选一（推荐） | C：守线肉鸽塔防 |
| --- | --- | --- | --- |
| 玩家操作 | 左右拖动 | 左右拖动 + 升级时点选卡片 | 只点选卡片 |
| 火力来源 | 只有人数和门 | 人数 × 武器 × 技能构筑 | 技能构筑 |
| 割草爽感 | 中，靠人多 | 高，人多加群攻技能 | 高 |
| 符合用户描述 | 符合 | 最符合 | 不符合（没有走位） |
| 耐玩度 | 低，几关就重复 | 中高，每局构筑不同 | 高 |
| 开发量 | 小 | 中 | 中 |

推荐 B：A 的操作就是广告里那套，好上手；再加上 C 的三选一构筑，割草的群攻手段才有来源，每局玩法也不重复。开发量比 A 只多一个升级选卡界面和一个技能池。

## 单局结构（方案 B）

一关 90 到 150 秒，分三段：

```mermaid
flowchart LR
  A[推进段 60-100 秒<br/>门 + 杂兵波 + 1-2 个精英] --> B[关底精英墙或 Boss 前门组]
  B --> C[Boss 战 30-60 秒<br/>小队停止推进]
  C --> D[结算：星级 + 奖励]
```

1. **推进段**：小队以 4 米/秒自动前进。每 8 到 12 秒出现一组门，门之间是杂兵波。击杀给经验，经验满了暂停游戏弹出三选一。
2. **精英**：带血条的大块头，挡在车道中间，击杀必掉一次额外三选一。
3. **Boss 战**：小队停在 Boss 场地，Boss 从前方逼近，地面红圈预警后放技能，玩家左右走位躲技能。非 Boss 关的关底换成一堵精英墙。
4. **失败条件**：小兵数量降到 0。

## 核心循环

- 局内：走位选门 → 人数和武器变强 → 清怪攒经验 → 三选一构筑 → 打精英和 Boss。
- 局外：通关拿金币和武器零件 → 升级起始人数、攻击、武器起始等级 → 打下一关。
