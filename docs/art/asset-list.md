# 素材清单

> v0.4，2026-10-09，已对齐策划设计稿 v0.1（`docs/design/`，按推荐方案 B：门跑酷 + 局内三选一）。规格见 `docs/art/style-guide.md`。
> v0.4 变更：用户选定 Kenney 路线，士兵、武器、行走者、快跑者、精英全部换成 v3 模型（Kenney 式倒角方块 Q 版）。v2 模型移到 `assets/models/_v2/`，v2 样张移到 `docs/art/samples/_v2/`。
> 美术方向：Q 版（chibi），v3 起为 Kenney 式倒角方块造型（大方头，约 2–2.3 头身），用户于 2026-10-09 拍板。v3 样张：`docs/art/samples/sample_soldier_tiers.png`、`docs/art/samples/sample_zombies.png`、`docs/art/samples/sample_lineup_v4.png`，前后对比 `docs/art/samples/sample_v2_vs_v3.png`。
> **Kenney 来源（CC0）**：士兵按 Kenney Mini Characters 的 `character-male-c` 的比例、部件布局和五官布局逐个部件重建；僵尸按 Kenney Graveyard Kit 的 `character-zombie` 重建；精英只借用 Kenney 的倒角方块风格。没有直接复制 Kenney 的顶点（原模型 700–1100 面、用渐变贴图），全部改为调色板 UV。许可证：`assets/models/LICENSE-kenney.txt`，署名：`assets/CREDITS.md`。生成脚本：`tools/art/gen_characters_v3.py`（`tools/art/blocky_lib.py`）。
> **导出约定（技术负责人要求）**：硬边、平面着色、颜色只走调色板 UV；glb 里**不导出平滑法线、不带顶点色属性（COLOR_0）**，描边用的平滑法线由引擎导入时计算并写进顶点色。`tools/art/verify_glb.py` 会检查这几项。
> 面数预算（已和技术负责人对齐）：士兵各档、普通僵尸高模 ≤450 面；行走者 / 快跑者另有 LOD1 ≤200 面（按距离切换，最近的约 100 个用高模）；武器每把 ≤120 面；精英 ≤1500 面；Boss ≤5000 面。普通僵尸从原点向前伸出不超过 0.6 米；精英碰撞半径 1.2 米（肩甲尖刺可以超出，只作装饰）。
> 阶段：**M1** = 第 1–3 关可玩切片必须有；**M2** = 第 1 章其余关卡（4–10 关）需要；**后续** = 第 2 章以后。

## 我方小队

可见士兵模型最多 40 个（`squad-and-gates.md`），所以士兵身体和武器拆成两个 MultiMesh：身体换动作，武器按等级换网格。

士兵外观分三档，跟武器等级绑定（见 `docs/design/squad-and-gates.md`）：a 档 = 手枪，b 档 = 步枪和霰弹枪，c 档 = 加特林和火箭炮。换档只换 MultiMesh 的网格，不增加 draw call。三档共用同一个姿势，武器以偏移 0 对齐到士兵双手。v3 改为右胯前持枪（枪轴约 x=+0.33 米），因为 Kenney 式大头在后上方镜头里会挡住居中的枪；枪的造型沿用 v2 并加粗（细枪管改为方截面），不是 Kenney 派生。M1 用 a、b 两档，c 档提前做好。
